---
title: Installation
description: Add Breakify 0.3.0 to a Flutter project.
---

Add Breakify 0.3.0 to your Flutter application:

```yaml
dependencies:
  breakify: ^0.3.0
```

Then import the public package API:

```dart
import 'package:breakify/breakify.dart';
```

## Next steps

Once the dependency is available in your project, continue to the [Quick Start](/quick-start/) or explore the [Fundamentals](/fundamentals/breakpoints/).
