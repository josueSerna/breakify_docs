---
title: Default Breakpoints
description: The default Breakify breakpoint thresholds.
---

Breakify provides five default minimum widths:

| Name | Minimum width |
| --- | ---: |
| `sm` | 640 |
| `md` | 768 |
| `lg` | 1024 |
| `xl` | 1280 |
| `xxl` | 1536 |

The configured breakpoint is active at its exact threshold. These defaults can be replaced through `BreakifyScope`.
