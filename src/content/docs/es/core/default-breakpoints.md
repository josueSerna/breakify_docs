---
title: Breakpoints predeterminados
description: Umbrales predeterminados de Breakify.
---

| Nombre | Ancho mínimo |
| --- | ---: |
| `sm` | 640 |
| `md` | 768 |
| `lg` | 1024 |
| `xl` | 1280 |
| `xxl` | 1536 |

El breakpoint configurado se activa en su umbral exacto. Puedes reemplazar estos valores mediante `BreakifyScope`.
