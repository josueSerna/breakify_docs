---
title: Layout adaptativo de aplicación
description: Combina scope, visibilidad, navegación y layouts.
---

Una aplicación práctica puede usar `BreakifyScope` en la raíz, `BreakifyNavbar` para navegación, `BreakifyVisibility` para sidebars y `BreakifyPanelLayout` para el contenido de la página. Resuelve valores con `context.resolve` en lugar de repetir comprobaciones de ancho.
