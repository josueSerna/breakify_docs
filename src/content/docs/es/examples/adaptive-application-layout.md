---
title: Layout adaptativo de aplicación
description: Combina varios widgets de Breakify.
---

Una aplicación puede usar `BreakifyScope` en la raíz, `BreakifyNavbar` para navegación, `BreakifyVisibility` para sidebars y `BreakifyPanelLayout` para el contenido. Resuelve valores con `context.resolve` en lugar de repetir comprobaciones de ancho.
