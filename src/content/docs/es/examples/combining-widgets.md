---
title: Combinar widgets de Breakify
description: Compón una pantalla responsiva con primitivas de Breakify.
---

Comienza con `BreakifyScope` y elige el widget más pequeño que exprese cada decisión: valores para propiedades, `BreakifyBuilder` para ramas personalizadas, grids para contenido repetido y widgets de panel y layout para la estructura de página. Esta composición mantiene el comportamiento responsivo explícito y comprobable.
