---
title: Instalación
description: Añade Breakify 0.3.0 a un proyecto Flutter.
---

Añade Breakify 0.3.0 a tu aplicación Flutter:

```yaml
dependencies:
  breakify: ^0.3.0
```

Después importa la API pública:

```dart
import 'package:breakify/breakify.dart';
```

## Próximos pasos

Cuando la dependencia esté disponible, continúa con el [inicio rápido](/es/quick-start/) o explora los [Fundamentos](/es/fundamentals/breakpoints/).
