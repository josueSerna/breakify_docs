Breakify es un toolkit de layouts responsivos para Flutter. Permite crear interfaces adaptativas usando breakpoints, valores responsivos, interpolación fluida y widgets listos para usar.

Esta documentación cubre Breakify **0.3.0**, incluida la actualización `heightMode`, que reemplaza la opción anterior `equalHeight` en los widgets de grid.
