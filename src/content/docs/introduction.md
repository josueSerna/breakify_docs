Breakify is a responsive layout toolkit for Flutter. It helps you build and maintain adaptive interfaces using breakpoints, responsive values, fluid interpolation and ready-to-use widgets.

This documentation covers Breakify **0.3.0**, including the `heightMode` update that replaces the former `equalHeight` option in the grid widgets.
